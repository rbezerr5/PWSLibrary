# PowerShell Library

A collection of PowerShell scripts, functions, modules, and automation examples designed to help beginners and IT professionals learn, automate, and improve their PowerShell skills.

## Objectives

This repository aims to provide:

- Beginner-friendly PowerShell examples
- Reusable functions
- Automation templates
- System administration scripts
- Windows troubleshooting tools
- Best practices and coding standards

## Repository Structure

### Scripts

Ready-to-use scripts for common administrative tasks.

Examples:

- Get-SystemInfo
- Get-InstalledApps
- Restart-ServiceSafely

### Modules

Reusable PowerShell modules that can be imported into other projects.

### Examples

Learning-focused examples covering:

- Variables
- Loops
- Arrays
- Functions
- Error Handling
- Objects
- Pipelines

## Requirements

- PowerShell 5.1 or later
- Windows PowerShell or PowerShell 7+
